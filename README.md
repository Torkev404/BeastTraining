# Python Data Cleaning Basics (OpenClassrooms Practice)

This notebook contains my hands-on practice exercises focused on data cleaning fundamentals in Python, completed as part of my preparation and coursework with OpenClassrooms.

The goal was to build solid habits around handling messy data, understanding data types, and preparing datasets for exploratory data analysis (EDA).

---

## 📌 What’s Inside

- **Data Inspection:** Checking shapes, data types, summary statistics, and missing values (`.info()`, `.describe()`, `.isna()`).
- **Handling Missing Data:** Detecting, filtering, and deciding when to impute or drop `NaN` entries.
- **Data Transformation & Type Casting:** Converting columns to proper data types (dates, numeric scales, strings).
- **String & Column Standardization:** Cleaning up headers, whitespace, and formatting inconsistencies.
- **Sanity Checks & Validations:** Identifying outliers, unexpected duplicates, and structural anomalies.
